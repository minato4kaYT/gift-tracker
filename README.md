# Gift Tracker — DEMO

Демо-клон трекера ресейла NFT-подарков (по мотивам @GiftTrackers_bot).
Запускается с **одним токеном бота** — без userbot и Telegram Premium.

## Что внутри
- Воронка 1:1: `/start` → меню (Профиль, Подписка, Рефералка, Попробовать бесплатно).
- Триал (3 ч, один раз), правила, активация, одноразовая инвайт-ссылка в чат логов.
- Тарифы (TON / Stars) — в демо оплата заглушена.
- Реферальная программа со ссылкой `?start=ref_<id>`.
- **Карточки листингов** «НОВЫЙ ЛИСТИНГ» с premium-эмодзи + кнопки
  Занять / Открыть лот (`t.me/nft/<slug>`) / Продавец.
- Логика **«Занять»** (first-come claim, счётчик «Воркнуто лотов»).
- Фейковый фид (`sources/demo_feed.py`) сам постит лоты в чат каждые N сек.

## Запуск
```bash
cp .env.example .env      # впиши BOT_TOKEN, LOG_CHAT_ID, ADMIN_IDS
pip install -r requirements.txt
python run.py
```
1. Создай бота у @BotFather, вставь токен.
2. Создай группу/канал «логов», добавь бота **админом**, возьми её id → `LOG_CHAT_ID`.
3. Запусти — бот начнёт постить демо-листинги; жми «Занять».
4. `/demo` (для админа) — отправить один листинг вручную.

## Premium-эмодзи
Поставь `USE_PREMIUM_EMOJI=1` **только** если у владельца бота есть Telegram Premium —
тогда 🎁🪙⭐️… отрендерятся как кастомные (id вытащены в `emoji_ids.py`).

## Из демо → в прод

- добавить клиентов Tonnel / Portals / MRKT.
- подключить реальные платежи (TON / Telegram Stars) в `buy:*`.
